🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

🚀 Features

- 👥 Two-player gameplay
- 🏆 Winner detection
- 🤝 Draw detection
- 🔄 Restart game option
- 📱 Simple and responsive design

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🎯 How to Play

1. Player 1 uses X.
2. Player 2 uses O.
3. Take turns placing your symbol.
4. The first player to get three symbols in a row wins.
